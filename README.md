## Firmware Features

### Relapse

Relapse is a public PS5 exploit chain that combines a browser-based entry point with kernel exploitation.

Its reported capabilities include:

- Kernel read/write access.
- Arbitrary code execution.
- ELF payload loading.
- Homebrew environment initialization.
- Integration with compatible payloads.

Relapse is not a permanent firmware replacement. It must be activated again after a complete system reboot.

### etaHEN

etaHEN is an all-in-one homebrew enabler for jailbroken PS5 systems.

Features include:

- Homebrew and payload support.
- Custom plugin loading.
- etaHEN Toolbox.
- Cheat management.
- FTP functionality.
- Game and application management.
- Hardware monitoring overlays.
- Kstuff integration.
- System configuration options.

### Kstuff

Kstuff provides kernel patches used by compatible PS5 homebrew environments.

Its functionality depends on firmware-specific support and the installed etaHEN release.

### Linux Support

PS5 Linux development allows compatible consoles to run Linux-based environments.

Features under development and available configurations include:

- Linux boot environments.
- Desktop Linux distributions.
- Development and testing tools.
- Hardware-specific configuration.
- GPU and system performance research.

Linux compatibility is more restricted than the public homebrew exploit range. Do not assume that every firmware supported by Relapse can boot Linux.

## FAQ

### 1. What is a PS5 jailbreak?

A PS5 jailbreak uses software vulnerabilities to enable code execution and additional system functionality beyond the standard retail environment.

### 2. What is Relapse?

Relapse is a public PS5 exploit chain that provides kernel-level access on supported firmware versions.

### 3. What is etaHEN?

etaHEN is an all-in-one homebrew enabler that provides payload, plugin, and system utility functionality.

### 4. What is Kstuff?

Kstuff is a collection of kernel patches used by compatible PS5 homebrew environments.

### 5. Which PS5 firmware versions are supported?

The public Relapse release supports firmware 7.00 through 13.60. Newer firmware versions should not be considered supported without a confirmed public release.

### 6. Does the jailbreak survive a reboot?

Relapse is tethered. A complete reboot requires activating the exploit again.

### 7. Does Relapse work on PS5 Slim and Pro?

The reported public exploit compatibility includes original, Slim, and Pro hardware, subject to firmware requirements.

### 8. Can I run Linux on a jailbroken PS5?

Linux is possible on selected configurations, but its firmware and hardware requirements are more restrictive than general homebrew support.

### 9. Can I install plugins?

Yes. etaHEN includes a plugin environment, but each plugin must be compatible with the installed version.

### 10. Can I update my PS5 after jailbreaking?

Updating may remove access to the public exploit. Check compatibility before installing any system update.

### 11. Is etaHEN the same as GoldHEN?

No. etaHEN is a PS5-focused homebrew enabler. GoldHEN is primarily associated with the PS4 scene.

### 12. Does jailbreak automatically make every PS5 game compatible?

No. Game compatibility depends on the system firmware requirements, available patches, and the capabilities of the installed tools.
